# 🏠 GharMol — House Price Predictor

A full-stack house price prediction web app using **Linear Regression** (scikit-learn), a **Flask** REST API, and a clean **HTML/CSS/JS** frontend.

---

## 📁 Project Structure

```
house-price-predictor/
├── frontend/
│   └── index.html          # UI — open directly in browser
├── backend/
│   └── app.py              # Flask REST API
├── model/
│   ├── housing_data.csv    # Sample training dataset
│   ├── train_model.py      # Model training script
│   └── house_price_model.pkl  # Saved model (generated by train_model.py)
├── requirements.txt
└── README.md
```

---

## ⚡ Quick Start

### 1. Install Python dependencies

```bash
pip install -r requirements.txt
```

### 2. Train the ML model

```bash
cd model
python train_model.py
```

Expected output:
```
Dataset loaded: 102 rows, 6 columns
Model Performance:
  MAE : ₹3,377,752
  R²  : 0.7208
Model saved → .../model/house_price_model.pkl
Supported locations: ['Bangalore', 'Chennai', 'Delhi', 'Hyderabad', 'Mumbai', 'Pune']
```

### 3. Start the Flask API

```bash
cd backend
python app.py
```

The API will be live at `http://localhost:5000`

### 4. Open the frontend

Simply open `frontend/index.html` in your browser.  
No web server needed — it calls the Flask API directly.

## 🔌 API Reference

### `GET /`
Health check.

```json
{ "status": "ok", "message": "House Price Prediction API" }
```

### `GET /locations`
Returns supported cities.

```json
{ "locations": ["Bangalore", "Chennai", "Delhi", "Hyderabad", "Mumbai", "Pune"] }
```

### `POST /predict`
Predict house price.

**Request body:**
```json
{
  "location":  "Mumbai",
  "sqft":      1500,
  "bedrooms":  3,
  "bathrooms": 2,
  "bhk":       3
}
```

**Response:**
```json
{
  "predicted_price": 12345678.90,
  "formatted_price": "₹1.23 Crore",
  "input": {
    "location":  "Mumbai",
    "sqft":      1500,
    "bedrooms":  3,
    "bathrooms": 2,
    "bhk":       3
  }
}
```

**Error response:**
```json
{ "error": "Unknown location 'Kolkata'. Choose from: Bangalore, ..." }
```

## 🤖 Machine Learning Details

| Property | Value |
|---|---|
| Algorithm | Linear Regression |
| Library | scikit-learn |
| Features | Location (encoded), sqft, bedrooms, bathrooms, BHK |
| Preprocessing | LabelEncoder (location), StandardScaler (numerics) |
| Saved with | `pickle` |
| R² Score | ~0.72 |

## 📊 Sample Dataset

The dataset (`model/housing_data.csv`) contains 102 real-estate entries across 6 Indian cities with the following columns:

| Column | Description |
|---|---|
| location | City name |
| sqft | Built-up area in sq ft |
| bedrooms | Number of bedrooms |
| bathrooms | Number of bathrooms |
| bhk | BHK configuration |
| price | Price in INR (₹) |

## 🚀 Extending the Project

- **Add more cities** — append rows to `housing_data.csv` and retrain
- **Better model** — swap Linear Regression for Random Forest or XGBoost
- **Persistent DB** — store predictions in SQLite with Flask-SQLAlchemy
- **Deploy** — host the Flask API on Render/Railway and the frontend on Netlify
